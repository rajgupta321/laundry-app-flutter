# 🧺 Flutter Laundry Service App

A complete **Laundry Service Application** built using **Flutter + Firebase**.

This project includes a **User Mobile App** and an **Admin Dashboard** for managing laundry orders in real time.

---

# 🚀 Features

## 👤 User App

• User Authentication (Login / Signup)
• Place Laundry Orders
• Track Order Status
• Real-time Updates
• Chat Support with Admin
• Push Notifications

## 🛠 Admin Panel

• Admin Login
• Dashboard Overview
• Manage Orders
• Update Order Status
• View Users
• Chat with Customers

# 🛠 Installation

Clone the repository

git clone https://github.com/rajgupta321/laundry-app-flutter.git

Open project folder

cd laundry-app-flutter

Install dependencies

flutter pub get

Run the app

flutter run
