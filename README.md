# Laundry App (Flutter + Firebase)

A complete Laundry Service Application built with Flutter and Firebase.

This project includes:

• User Mobile App  
• Admin Dashboard  
• Real-time Order Management  
• Firebase Authentication  
• Cloud Firestore Database  
• Push Notifications  

---

# Project Structure

laundry-app-flutter
│
├── laundry_app        # User mobile application
├── laundry_admin      # Admin dashboard
├── apk                # Installable APK files
└── screenshots        # App screenshots

---

# Features

## User App

• User Registration & Login  
• Place Laundry Orders  
• Order Tracking  
• Real-time Status Updates  
• Chat Support  
• Notifications  

## Admin Panel

• Admin Login  
• View All Orders  
• Update Order Status  
• Manage Users  
• Dashboard Overview  
• Chat with Users

# Installation

Clone the repository

git clone https://github.com/rajgupta321/laundry-app-flutter.git

Go to project folder

cd laundry-app-flutter

Run Flutter project

flutter pub get  
flutter run
